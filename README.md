## StockAnalysis
Is a web application that analyzes stocks using data from Finnhub API to give a "buy score" out of 100 based on my own investment criteria.

## Built With
- Python
- Flask
- HTML
- CSS
- Finnhub API
- Git
- Github
- Render

## Scoring Model

P/E Ratio:          **25%**  
Revenue Growth:     **20%**  
Return of Equity:   **20%**  
Debt/Equity Ratio:  **15%**  
Current Ratio:      **10%**  
52-Week Position:   **10%**  
Percent Change:     **Up to +5 bonus points**

The StockAnalysis scoring algorithm prioritizes stocks that are:
- **Financially healthy**
- **Likely to grow**
- **Good Value**

The goal of the application is to score stock based on my personal criteria to balance less risk, growth, and value of stock.
